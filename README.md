# qa-mcp: автоматический QA готового веб-проекта

MCP-сервер (Python + FastMCP + Playwright). Открывает проект в реальном браузере, сам жмёт кнопки и ищет баги
в дизайне. Результат: краткая сводка и `report.md` со скриншотами, где проблемные места обведены красным.

## Инструменты

| Инструмент | Что проверяет |
|---|---|
| `full_qa(target, max_pages=10)` | Всё ниже сразу |
| `test_interactions(target)` | Мёртвые кнопки; отключённые, что всё равно реагируют; «кликабельный» вид без реакции; перекрытые кнопки; форма уходит с пустыми обязательными полями; двойной клик шлёт запрос дважды; битые якоря и ссылки-заглушки |
| `test_layout(target, widths=[...])` | На ширинах 320/375/768/1024/1440: наложение текста, обрезанный текст, горизонтальный скролл, контраст текста (в том числе на картинках), мелкие зоны нажатия |
| `test_fonts(target)` | Число шрифтов, шрифты-«чужаки», незагрузившиеся веб-шрифты, разброс размеров, иерархия заголовков |
| `test_images(target)` | Битые, растянутые, «мыльные», тяжёлые картинки, нет `alt` |
| `quick_security(target)` | Секреты в файлах и истории git, `.env` в git, нет `.gitignore`; у сайтов по URL: CSP, HSTS, X-Frame-Options, nosniff, Referrer-Policy, HTTP, mixed content, флаги cookie |

`target`: URL (`https://...`) или путь к папке/файлу проекта (для папки поднимается временный локальный сервер).
Отчёты пишутся в `reports/<дата-время>/report.md`.

## Что НЕ проверяется

- Смысловое сочетание фото и надписей: нужен «глаз», а проверяются только измеримые вещи.
- Логика приложения и бэкенда, обработчики кликов без `cursor:pointer` на не-кнопках.
- Заголовки безопасности для `localhost` (их там не бывает); проверяются только реальные сайты.

## Безопасность самого сервера

- Только чтение: проект не изменяется. Клики выполняются в изолированном контексте браузера, без cookies пользователя.
- Переходы на внешние домены блокируются и записываются в отчёт; внешние подресурсы грузятся с таймаутом 5 с.
- Секреты в отчёте маскируются (показаны первые 4 и последние 2 символа).
- Лимиты: число страниц, время на страницу.

## Запуск и подключение

```
.venv\Scripts\python.exe server.py
claude mcp add qa-tester -- "<путь>\.venv\Scripts\python.exe" "<путь>\server.py"
```

Переустановка: `python -m venv .venv`, `pip install fastmcp playwright httpx pytest pillow`,
затем `PLAYWRIGHT_BROWSERS_PATH=<путь>\browsers python -m playwright install chromium`.

## Тесты

`.venv\Scripts\python.exe -m pytest tests -q`. Есть фикстуры с заведомыми багами, «чистые» страницы и регрессии,
найденные на реальном сайте (плотные строки текста, декоративные символы, полупрозрачная шапка, ссылка `#top`).
